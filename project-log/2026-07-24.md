# 2026-07-24 개발 기록

Baseball AI Coach 프로젝트의 프론트엔드 UI/UX 설계 및 대화형 시각화 화면 구축 완료에 이어, 백엔드 API 서버(Spring Boot + MySQL)의 뼈대와 DB 엔티티 설계/구축 완료. 수비/공격 팀에 따른 야구장 라인업 동적 정합성 보완, 실시간 수비 라인업 및 실시간 공격 타순(1~9번) 관리 에디터 추가 적용 완료.

## 🚨 트러블슈팅 및 에러 조치 내역

### 1. PowerShell 환경에서의 `&&` 연산자 에러
- **원인**: Windows PowerShell 환경에서 `&&` 체이닝 연산자를 사용하여 npm 패키지 설치 시 구문 파싱 에러 발생.
- **해결**: 명령어를 분리하여 순차적으로 실행하여 안정적인 패키지 주입 완료.
- **상세**: [TROUBLESHOOTING.md #1](file:///c:/PolarBear_Projects/baseball-ai-coach/TROUBLESHOOTING.md#1-powershell-환경에서의-&&-연산자-구문-파싱-에러)

### 2. npm 라이브러리 설치 시간 초과에 따른 비동기 대기
- **원인**: `recharts` 및 `lucide-react` 패키지 다운로드 및 의존성 분석 시 Windows 디스크 및 네트워크 지연으로 인해 3분 이상 소요되어 로컬 커맨드 `WaitMsBeforeAsync`를 초과하여 백그라운드 태스크로 전환됨.
- **해결**: 백그라운드 태스크의 완료 감지 및 `manage_task` 상태 확인을 동반하여 다음 작업을 대기함으로써 안정적으로 의존성 주입 확인.
- **상세**: [TROUBLESHOOTING.md #2](file:///c:/PolarBear_Projects/baseball-ai-coach/TROUBLESHOOTING.md#2-npm-의존성-설치-시간-지연에-따른-백그라운드-태스크-전환)

### 3. `getUpdatedDefenders is not defined` React 컴파일 참조 에러
- **원인**: 수비 팀 라인업 바인딩 로직 리팩토링 후, 리액트 스코프에서 제거된 구 버전의 헬퍼 함수 호출 코드가 렌더링 프롭스단에 남아 런타임 ReferenceError 발생.
- **해결**: 컴포넌트에 넘기는 프롭스를 동적 상태 변수 자체(`defenders={defenders}`)로 변경하여 컴파일 정상 복구.
- **상세**: [TROUBLESHOOTING.md #3](file:///c:/PolarBear_Projects/baseball-ai-coach/TROUBLESHOOTING.md#3-getupdateddefenders-is-not-defined-react-컴파일-참조-에러)
