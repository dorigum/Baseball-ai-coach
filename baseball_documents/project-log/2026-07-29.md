### 2. 전역 고딕 폰트(Noto Sans KR) 강제 통일 및 모노스페이스 배제

  - `index.css`를 통해 `body`, input 폼은 물론 SVG 내부 `text` 태그까지 고딕 글꼴로 전역 강제 덮어쓰기 적용.
  - 라인업 및 공격 타순 내 포지션 폰트를 `font-mono`에서 `font-sans`로 변경하고, 상/하단 폰트 크기 및 두께를 동일하게 `text-[10.5px] font-black text-slate-400`로 상향 통일하여 시각적 대칭성 확보.

### 3. 야구장 이미지 렌더링 영역 극대화
- **해결 내역**:

  - 야구장 카드의 컨테이너 패딩을 기존 `p-16` ➡️ `p-6` ➡️ `p-2`로 한 번 더 최종 축소하여, 확장된 공간 전체를 SVG 구장이 꽉 채우도록 시각적 크기 극대화.

### 4. 위키미디어 이미지 핫링크 차단(Referer 403 Forbidden) 우회 조치
- **발생한 문제**: 위키미디어 이미지 URL을 `<img src>`에 바인딩 시 외부 도메인 직접 요청 차단 정책(Referer 체크)에 의해 403 Forbidden 에러가 발생하고 엑스박스(깨짐) 현상이 나타남.
- **해결 내역**:
  - 스코어보드 내의 엠블럼 이미지를 출력하는 두 개의 `<img>` 태그에 **`referrerPolicy="no-referrer"`** 속성을 부여하여 참조 페이지 헤더를 노출하지 않도록 조치. 위키미디어의 핫링크 제한 우회에 성공함.

- **도입 취지**: 텍스트(구종, 구속) 위주 기록을 탈피해 투수의 볼배합 궤적 코스를 정밀하게 추적하고 히트맵으로 한눈에 파악할 수 있는 시스템 구축.
- **구현 세부**:
  - **백엔드**: `PitchRecord.java` 엔티티와 `PitchRecordRequestDto`, `DashboardResponseDto.PitchLogDto` 에 `pitchZone` (Integer, Nullable) 필드를 확장하고 저장/조회 로직 연계. 자바 컴파일 무결성 검증 완료.
  - **StrikeZone 컴포넌트 신규 작성 (`StrikeZone.jsx`)**: 포수/타자 시점에서의 3x3 스트라이크 존(1~9번)과 상하좌우 외곽 볼 구역(10: 상, 11: 우, 12: 하, 13: 좌)을 격자로 구현한 SVG 기반 13분할 코스 선택기 구축.
  - **기록 입력기 연동 (`PlayInputPanel.jsx` / `App.jsx`)**: 구속 슬라이더 밑에 이식하고 투구 기록 추가 시 `pitchZone` 정보를 백엔드로 전달하도록 구성. (코스 선택 누락 시 경고창 팝업 방어 처리)
  - **대시보드 실시간 히트맵 (`Dashboard.jsx`)**: 누적된 로그 속 `pitchZone` 빈도수를 연산해 비율이 높을수록 짙은 빨간색/오렌지색 네온 음영(`rgba(239, 68, 68, opacity)`)으로 13개 셀이 가열 렌더링되게 구현. 우측에 가장 많은 투구가 몰린 코스 순위(TOP 5)와 해당 구역의 주요 구종 통계를 전술 표로 함께 출력.

### 6. 🤖 AI 제안 수비 포지션 가이드 핀/점선 오버레이 시각화 및 자동 적용 연동 (방안 A)
- **도입 취지**: AI 코치의 텍스트 시프트 조언을 야구장 필드 위에 도식화하여 실용성을 극대화하고 전술을 한눈에 직관하도록 돕기 위함.
- **구현 세부**:
  - **백엔드**: `AiAdviceService.java` 프롬프트에 분석 완료 시 맨 끝에 `[RECOMMENDED_SHIFT: <SHIFT_TYPE>]` 메타 꼬리표를 반환하도록 지시.
  - **실시간 파싱 및 상태 동기화 (`App.jsx`)**: API 응답 수신 시 정규식으로 꼬리표를 감지하여 본문에서는 은폐하고 `recommendedShift` 상태에 저장. 로컬 폴백 엔진(`triggerLocalFallback`)에서도 주자 및 이닝 상태에 따라 `BUNT`, `DEEP`, `PULL_LEFT` 등 코드를 동적 매핑하도록 보완.
  - **가이드 핀 및 지시선 오버레이 (`BaseballField.jsx`)**: 5종 시프트별 좌표 맵(`shiftCoordinates`)을 정의해 SVG 야구장 위에 권장 위치를 반투명한 연두색 점선 가이드 원으로 오버레이 표시. 현재 핀에서 가이드 핀 방향으로 향하는 얇은 점선 지시선(화살표 가이드)을 드로잉하여 드래그 배치에 엄청난 가시성 제공.
  - **원클릭 자동 시프트 적용**: AI 추천 시프트 감지 시 헤더에 바운스 애니메이션 버튼(`🤖 AI 추천 [시프트명] 적용`)이 자동 노출되며, 클릭 한 번에 9개 수비 핀이 추천 시프트 좌표로 한순간에 100% 자동 정렬 적용되도록 연동.

## 🛠️ 트러블슈팅 및 장애 조치 이력

### 20. 위키미디어 이미지 핫링크 차단(Referer 403 Forbidden) 우회 조치
- **장애 요인**: 위키백과 미디어 서버에서 외부 도메인으로의 직접적인 이미지 핫링크에 대해 Referer 검증을 통해 403 에러를 발생시켜 구단 엠블럼 이미지가 엑스박스로 보임.
- **조치 내역**: React 컴포넌트 내 `<img>` 태그에 `referrerPolicy="no-referrer"` 속성을 부여하여, 참조 사이트 정보를 전송하지 않고 익명으로 호출하도록 함으로써 핫링크 방지 봇의 필터링을 우회하고 고해상도 로고 렌더링에 성공함.
