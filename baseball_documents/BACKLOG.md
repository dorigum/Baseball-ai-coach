# Baseball AI Coach 추후 개발 예정 기능 (백로그)

Baseball AI Coach 프로젝트의 UX 편의성 및 데이터 전술 분석 깊이를 더하기 위해 제안된 **차기 개발 예정 고도화 기능 백로그** 목록입니다.

---

## 📌 우선순위 로드맵 개요

| 우선순위 | 기능명 | 구현 기술 | 기대 효과 |
| :---: | :--- | :--- | :--- |
| **High** | 🔥 1. 투구 코스 히트맵 구종별 실시간 필터칩 | React State Filtering | 구종별 탄착군 및 핫코스 분리 분석 제공 |
| **Medium** | 🔊 2. AI 전술 조언 음성 리포팅 캐스터 (TTS) | Web Speech Synthesis API | 현장/덕아웃 입력 시 청각 브리핑으로 가독성 보완 |
| **Medium** | 🏟️ 3. KBO 명승부 전술 체험 시나리오 프리셋 | Preset Data Mapping | 원클릭으로 주자/볼카운트/매칭 데이터 즉시 주입 |
| **Low** | 🎙️ 4. 음성 인식 전술 기록 입력기 (STT) | Web Speech Recognition API | 타이핑 없는 초고속 상황 음성 타이핑 지원 |

---

## 🛠️ 기능별 상세 기획 및 설계 가이드

### 1. 🔥 투구 코스 히트맵 구종별 실시간 필터칩 (High)
- **개념**: 현재 모든 투구를 합산하여 그리는 13분할 히트맵에 "구종별 필터링"을 적용해, 특정 구종의 탄착군만 따로 관측하도록 지원합니다.
- **설계 방향**:
  - `Dashboard.jsx` 내 히트맵 영역 상단에 `[전체]`, `[직구]`, `[슬라이더]`, `[커브]`, `[체인지업]` 등의 필터 버튼 그룹(칩)을 렌더링합니다.
  - 필터 칩 선택 시 `pitchLogs` 중 해당 `pitchType`을 지닌 데이터만 걸러서 분포율 분모/분자를 재계산하고, 히트맵 네온 강도 및 TOP 5 핫코스 랭킹 표를 실시간 갱신합니다.
  - 이를 통해 특정 구종에 대한 투수의 제구 편향성을 단번에 프로파일링할 수 있습니다.

### 2. 🔊 AI 전술 조언 음성 리포팅 캐스터 - TTS (Medium)
- **개념**: AI가 도출해 준 전술 조언 텍스트를 야구 캐스터 어조의 오디오 음성으로 음성 합성하여 들려줍니다.
- **설계 방향**:
  - 조언 텍스트 출력 카드 타이틀 영역 혹은 우측 하단에 🔊 **[조언 듣기 / 정지]** 토글 스피커 버튼을 개설합니다.
  - 웹 표준 브라우저 API인 `window.speechSynthesis` 및 `SpeechSynthesisUtterance` 객체를 연동합니다.
  - 한국어 목소리 엔진(`ko-KR`)을 할당하고, 덕아웃의 시끄러운 환경에서도 또박또박 들리도록 말하기 속도(rate: 1.05)와 음질 피치(pitch: 1.0)를 세밀하게 조정합니다.
  - 완전 무료(무제한) 스펙으로 클라우드 서버의 API 요금 부하를 유발하지 않습니다.

### 3. 🏟️ KBO 명승부 전술 체험 시나리오 프리셋 (Medium)
- **개념**: 사용자가 전술 분석을 바로 시뮬레이션해 볼 수 있도록 역사적 시나리오 혹은 기본 테스트 세트를 원클릭으로 셋팅해 줍니다.
- **설계 방향**:
  - 경기 정보 입력 패널 옆에 `[시나리오 체험 로드]` 드롭다운 혹은 버튼 세트를 노출합니다.
  - 대표 프리셋 예시:
    1. **2024 KS 9회말 승부처**: 투수 양현종 vs 타자 오지환 (주자 1루 신민재, 1볼-2스트라이크, 잠실구장)
    2. **번트 대비 정석 상황**: 투수 류현진 vs 타자 김도영 (주자 무사 1, 2루, 대구구장)
  - 프리셋 로드 버튼 터치 시 `App.jsx` 의 `gameInfo`, `pitchInfo`, `runners`, `count` 등의 상태들이 해당 상수 세트로 한순간에 초기화 세팅되어 AI 시프트와 분석 궤적을 즉시 체험할 수 있습니다.

### 4. 🎙️ 음성 인식 전술 기록 입력기 - STT (Low)
- **개념**: 자판 타이핑이 번거로운 현장 기록 환경에서 목소리를 활용해 투수/타자 이름 및 상황을 받아 적어 줍니다.
- **설계 방향**:
  - 인풋 필드 옆에 마이크 모양 아이콘 뱃지를 배치합니다.
  - 웹 표준 음성 인식 스펙인 `window.webkitSpeechRecognition`을 활성화하고 언어를 `ko-KR`로 지정합니다.
  - 수신된 음성 문자열을 파싱하여, 투수나 타자 명칭에 알맞게 폼 필드 텍스트에 다이렉트로 채워 주어 기록 편의를 극대화합니다.
